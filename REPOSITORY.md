# Repository Notes

This repository is intended to become the canonical source repository for the GameCoin protocol/node/wallet software.

The imported source baseline is GameCoin Public Testnet v0.8.3. The EmilyGaming website and Memspace frontend are maintained separately in the `emilygaming` repository; the `website_release/` directory remains here only as historical v0.8.3 release material and can be removed from the v0.9 development line once the split is complete.
