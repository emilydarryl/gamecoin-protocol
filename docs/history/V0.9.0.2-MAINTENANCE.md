# GameCoin v0.9.0.2 Candidate 2 Maintenance

This release is a **chain-compatible maintenance update** for Public Testnet v4.

It intentionally preserves:

- network ID `gamecoin-public-testnet-v4`
- P2P protocol `5`
- genesis hash `0c47cce8ff7bd89c7eacd298299e6259c249be87c569c4939784952cdfb5f304`
- RPC/P2P ports `20444` / `20445`
- Windows data directory `GameCoinPublicTestnetV4`
- installer AppId `{0307E05C-7398-40D2-9D9C-15842586C194}`

No consensus rule changes are included. Existing Public Testnet v4 blocks and wallets remain valid.

## Wallet activity display

The live height-101 maturity/fee test proved a fee-bearing coinbase of `5.00100000 GAME` on-chain while one GUI activity row showed the base `5.00000000 GAME` subsidy. The wallet now re-checks fee-bearing blocks that pay one of its mining addresses through the authoritative `/block/<height>` endpoint before rendering activity. This keeps the activity row tied to the exact stored block transaction.

A regression test covers a block-list/detail mismatch and requires the activity row to display the authoritative `5.00100000 GAME` coinbase.

## Other GUI cleanup

- Windows AppUserModelID now correctly names Public Testnet v4.
- The footer no longer calls the v4 chain a "v2 reset chain."
