# Security Policy

GameCoin is experimental cryptocurrency software. The current v0.8.3 release is a public-testnet build and has not received a production security or consensus audit.

## Reporting a vulnerability

Please do **not** open a public issue containing exploit details for vulnerabilities that could affect consensus, wallet keys, transaction validation, mining, peer-to-peer networking, or software update integrity.

Until a dedicated security contact is published, contact the repository owner privately through GitHub and include:

- affected version(s)
- a concise description of the issue
- reproduction steps or a proof of concept when safe
- expected impact
- suggested mitigation, if known

Please allow time for verification and remediation before public disclosure.

## Mainnet status

GameCoin is **not mainnet-ready**. Security-sensitive behavior may change during the v0.9.x mainnet-candidate phase.
